## Requirements (what, not how)
1. **Precision (A1).** float32 is the MACE default; the harmonic backend and everything else (positions, momenta, NM transforms, virial, statistics) stay float64. TF32 must be off explicitly (`torch.backends.cuda.matmul.allow_tf32 = False`, `torch.backends.cudnn.allow_tf32 = False`) and autocast must not be active during force calls. The JSON records the force dtype and the TF32/autocast state as actually read back, for both backends.
2. **Harmonic initialisation (A6), `--init harmonic` default.** The initial ring polymer is a seeded draw from the exact P-bead harmonic distribution of the PIMD-cell Hessian at g = 1 (light H), all normal modes including the centroid (classical amplitude), with zero amplitude on the 3 Gamma translations and on every imaginary or nonpositive mode. The Hessian is the one that defines the same-cell reference: the harmonic backend's own fc; for MACE, the cached FC (interpolated commensurate dynamical matrices) assembled into the real supercell Hessian, or `fd_hessian` of the PIMD cell when the Hessian check runs. Keep a non-harmonic option (all beads at x0) for diagnostics. Works for any P >= 1. The JSON records the init mode and which Hessian was used.
3. **Pre-equilibration (A6).** `--pre-equil N` (default 1000) steps at g = 1 before the first GL point, discarded; steps and wall time recorded. Not repeated on resume.
4. **Primary output (A2).** `delta_anh_meV_H = dF_PIMD,P - dF_harm,samecell,P` (analytic P-bead value, same commensurate q, same COM term, same folding as item 5). `delta_anh_inf_meV_H` against the infinite-P value is stored as a diagnostic. The existing rule that the primary value is null when the reference is unverified or invalid stays (and now also covers item 8). `compare_runs` compares Delta_anh, not raw dF, for P vs 2P and dt vs dt/2, and reports d = Delta_anh(larger P) - Delta_anh(smaller P) with sigma_d so the A4 pilot rule (reject P only if |d| > 0.3 and |d| > 1.96 sigma_d) can be applied from its output.
5. **Imaginary modes (A9).** The same-cell reference (both `harmonic_samecell` and `hessian_samecell`) yields a dropped value (current behaviour) and a folded value (|nu| for non-translation imaginary modes, as `decompose.py` does), each at infinite P and at P. Folded is primary when imaginary modes exist. Record `n_imag`, `folded`, `s_imag_meV_H = |folded - dropped|` per H, beta hbar |omega| of each folded mode, and the imaginary eigenvector(s). `valid` must no longer be False only because of folded imaginary modes; unverified translations or a non-translation mode at zero frequency (nothing to fold) still invalidate. Monitor: mean centroid displacement from x0 projected on each imaginary mode, in Å (retention gate < 0.1 Å), with the convention stated in the JSON.
6. **Stationarity (A6 ii).** Per GL point the kept samples are split in two halves; flag if |mean1 - mean2| > 3 sigma_half, where sigma_half is the standard error of that difference from the two halves' `stat_error` values (record the definition). One automatic extension (default 3000 steps, configurable) on failure, retested on all kept samples of that point; a second failure sets `stationarity_ok` False for the point and the run. The extension is recorded and is the only automatic extension.
7. **Structural monitors (A14).** Heavy-atom centroid RMSD from x0 (unwrapped; mean over the run and max), O-H coordination (nearest O of each H by centroid, minimum image) compared with x0, and a histogram of the proton-transfer coordinate d(O-H) - d(H...O) per H over beads. Fixed bins, compact. Per GL point and per run. The whole JSON stays small (target under 100 kB).
8. **Residual force (decision 17 A13).** max |F| at x0 with the run dtype, evaluated at x0 itself (not on the initialised polymer). Above 1e-3 eV/Å the run exits with a clear error before any expensive step, unless `--allow-invalid-reference` (default off) is given, in which case it runs, records `invalid_reference: true`, and the primary Delta_anh is null.
9. **Snapshots for C2.** `--dump-every K`: bead positions (float64, all P beads, unwrapped) every K kept steps per GL point to `<state-root>/<out stem>_g<j>.npz` (j = point index in `points`), self-describing enough to recompute K_H in float64 from the file alone (g, masses, H mask, cell, atomic numbers, step indices). Path and snapshot count recorded per point.
10. **Splitting.** `RingPolymer` constructor default becomes "baoab"; the CLI default stays baoab; splitting is recorded (it already is, keep it).
11. **Throughput.** Seconds per ring step (per point, pre-equilibration and run) and GPU peak memory recorded.
New CLI options join `run_args`, so a resume with different values still refuses to mix runs.

## Known pitfalls
* The free translation of the whole cell diffuses under the centroid thermostat (order 0.5 Å rms over a 13000-step run for a 96-atom cell). RMSD and the imaginary-mode projection must not read that as drift.
* `cell_atoms * sc` (ASE repeat order) and `ph.supercell` (phonopy order) order atoms differently, and phonopy's dynamical-matrix phase convention must be respected when assembling a supercell Hessian. Check the assembled Hessian against `harmonic_samecell` (same dF and dF_P) in a case where the two orders differ.
* With harmonic initialisation the polymer is no longer at x0, so `rp.f[0]` is no longer the residual force at x0.
* Imaginary modes at q != Gamma are complex Bloch modes. The supercell Hessian gives real modes on the same commensurate set.
* Some H have no acceptor O nearby, so their transfer coordinate is undefined. Record that; do not invent one.
* A 2-sigma test fails by chance about 5 % of the time. Fix the seed once. If the test fails, investigate before you reseed.
* Restart state holds q only, and momenta are resampled at each mass point. Dumps, extensions and pre-equilibration must survive an interrupted run and a resume without double counting.
