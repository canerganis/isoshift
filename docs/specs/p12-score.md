# Spec: p12-score (new src/isoshift_event/p12_score.py)

## Goal and why
P12 (`docs/predictions/P12_pimd.md`) is a predeclared path-integral check of the harmonic isotope double difference on five pairs. Its outcome rules (section 3) and the amendments A1 to A15 (section 2a, decisions 18 and 19) were all fixed before any PIMD data. This module turns the run JSONs into the verdict. It is the last link in a claims chain written blind, so it must apply the registered rules literally, with no tuning, and keep every failure visible (PLAN.md P6). Two jobs: `pilot` (decision 18 action 6, decision 19 action 4) writes `results/pimd/pilot_decision.json` before row 4 starts; `score` (decision 18 action 8, decision 19 action 9) writes `results/pimd/p12_scores.json` and prints a short markdown table.

Owned files (the only files you may create or edit): `src/isoshift_event/p12_score.py`, `tests/test_p12_score.py`. Do not edit `pimd.py`, `isoshift/`, `docs/`, `results/` or other tests. Do not commit; the conductor commits. CPU only, no MACE, no torch import at module level.

## Read first
P12 sections 1, 3 and 2a (A2, A4, A6, A9, A10, A11, A12, A13, A14, A15); decision 18 (A4, A6, A10, A11, actions 6 to 8); decision 19 (rules 1, 2, 4, 6, 7, action 9, the "worst non-F case" paragraph). Then `src/isoshift_event/pimd.py`: `document()` inside `main` (the run JSON schema), `compare_runs` (pilot d, sigma_d, seed refusal, factor-2 check, already implements the A4 reject flag), `HESSIAN_TOL_MEV`, the Hessian check block. `results/pimd/mp-625152_P16.json` is a real partial run (1 of 4 GL points); `results/pimd/controls_cpu.json`, `results/pimd/a4b_scan_residual.json`, `results/pimd/controls/c2_float64.py` (C2 output schema), `src/isoshift_event/decompose.py` and `results/decompose_pairs.csv`. `docs/math/` holds accepted formulas; use them, do not re-derive. Reuse `pimd.compare_runs` rather than duplicating the pilot difference.

## Inputs (units meV per H unless stated)
* Run JSONs `results/pimd/<struct>_P<P>.json`. Usable for scoring only with `status == "complete"`. Fields used: `P`, `struct_id`, `delta_anh_meV_H` (null when the reference is invalid or the FC interpolation unverified), `delta_anh_err_meV_H` (sigma), `error_converged`, `stationarity_ok` (and per point), `monitors.heavy_rmsd_ok`, `monitors.coordination_unchanged`, `monitors.retention_ok` (pooled keys too), `invalid_reference`, `initial_max_abs_F_eV_A`, `hessian_check` (None when q-points are exact; else `diff_meV_H`, `diff_P_meV_H`, `passed`), `fc_interpolation_verified`, `s_imag_meV_H`, `run_args.seed`, `seconds_per_ring_step`, `points[0].tau_int_steps`. Do not assume fields `pimd.py` does not write (there is no `diagnostic` flag in its output).
* `a4b_scan_residual.json`: `structures[id].a4b_bound_meV_H` keyed "16", "24", "32" (primary A_i(P)); `a4b_plateau_sensitivity_meV_H` (sensitivity only).
* `controls_cpu.json`: `s_dt_meV_H_by_P`, `s_quad_meV_H` (0.01), `C1_by_P[P][struct].pass`, `C4_by_P[P].pass`, top-level `pass`.
* C2: `results/pimd/c2_*.json` (`s_f32_meV_H`, `pass`, `stop_and_reconvene`, `P`). Not written yet; row 3 produces `c2_mp-625152_P16.json`.
* ddF_harm: P12 section 1 defines it as `ddF_total / H_per_atom` from `results/decompose_pairs.csv`, model `mace`. `results/screen_pairs_refined.csv` (`ddF_iso_300K_meV_H`) is a cross-check only; it differs on pair 5 by about 0.02.
* Optional: `results/pimd/pair2_beads.json` (decision 19 action 5, the pair 2 P choice), `pilot_decision.json` (branch).

## Requirements
1. **Orientation (A12).** b is the first id of the P12 label, a the second (struct_a in the CSV is the second id). Assert recomputed ddF_harm(b - a) = +5.03, +6.00, +3.07, +1.50, +5.80 for pairs 1 to 5 within 0.01; a mismatch raises.
2. **pilot.** From mp-625152 P16 and P32 (both complete): d = Delta_anh(32) - Delta_anh(16), sigma_d = hypot of the two errors; refuse a shared seed. Branch F iff |d| > 0.3 and |d| > 1.96 sigma_d (A4). Branch T iff tau_int at the first GL point of the P16 run exceeds 24 steps (A6). Measured s per ring step per run and rate factor f = measured / (1.23 s x P/16) against the chunk-4 smoke test (`docs/specs/pimd-p12-measurements.md`). s_f32 from C2, with its pass and stop flags carried through; stop_and_reconvene true must be impossible to miss in the output. If the JVASP-54682 P16 diagnostic and P32 runs both exist, also d_Fe and sigma_dFe as separate fields. Write the rule text with the numbers.
3. **Which run feeds which pair.** P per pair comes from the branch and the pair 2 choice, never from comparing outcomes: main branch pairs 1, 3, 4, 5 at P16 and pair 2 at the P in `pair2_beads.json` (32 or 24); branch F pairs 1 to 3 at P32, pairs 4 and 5 not run. On the main branch pair 3 uses mp-625152 P16 (row 2 only feeds d). The JVASP-54682 P16 run off branch F is the row 8 diagnostic: tagged diagnostic in the output, never in any ddF_corr. Assert equal P inside each pair; mixed P raises. Report P per pair.
4. **s_P per structure (decision 19 rule 4, verbatim).** P16: max(0.05, A_i(16), max(0, |d| - sigma_d)). P32 off branch F: max(0.05, A_i(32), max(0, |d| - sigma_d)/2, max(0, |d_Fe| - sigma_dFe)/2), the last term only if row 8 ran. P24: max(0.05, A_i(24), max(0, |d| - sigma_d)). Branch F: max(0.05, A_i(32), |d|/2). Record which term set each s_P.
5. **Other allowances.** s_hess: the measured Hessian-check difference for the interpolated structures mp-625054, JVASP-54682, JVASP-92228 (use the larger of the infinite-P and same-P |diff| the gate itself uses, state the choice), 0 for the others; a missing check on an interpolated structure is a gate failure. s_imag from the run. s_dt at the pair's P from `s_dt_meV_H_by_P`, s_f32 from C2, s_quad from controls, each counted once per pair.
6. **Per pair (A10).** sigma_pair = hypot(sigma_a, sigma_b); B_pair = s_dt + s_f32 + s_quad + s_P,a + s_P,b + s_hess,a + s_hess,b + s_imag,a + s_imag,b; E_pair = 1.96 sigma_pair + B_pair; ddF_corr = ddF_harm + Delta_anh(b) - Delta_anh(a). Category: `not run` (JSON missing or not complete), `invalid reference` (A13: `invalid_reference` or residual force above 1e-3 eV/A; expected for pair 5), `inconclusive` with the reasons (any failed gate: C1 or C4 missing or failed at the pair's P, C2 not passed, stationarity, Hessian check, retention, A14 heavy RMSD or coordination; or E_pair > 1), else `supported` (|ddF_corr| > E_pair, harmonic sign), `challenged` (resolved, opposite sign), `unresolved`. An unconverged statistical error is listed as its own inconclusive reason. Also report E_pair with the plateau sensitivity in place of A_i(P), and flag a pair that is inconclusive only through the fit allowance (decision 19 action 9).
7. **Hypotheses.** H1 over pairs 1 to 3, denominator 3: support iff all three supported; challenge iff any challenged; else undecided with the counts per category. H2 per pair 1 to 3 with half thresholds 2.515, 3.000, 1.535: supported if |Delta_anh(b) - Delta_anh(a)| + E_pair < half, exceeded if |...| - E_pair > half, else unresolved; not assessed if the pair is not scoreable. H3 (pair 4): sign of the correction (toward the rule's negative sign or not) and the sign of ddF_corr reported separately, each with whether it is resolved. H4 (pair 5): size and sign of the correction, or the reason it is absent. Missing or inconclusive pairs never count as support.
8. **Covariance.** Pairs 1 and 3 share b = mp-23807, so Delta_anh(mp-23807) enters both ddF_corr with the same sign; state cov = sigma_23807^2 and the correlation coefficient, and that s_P of mp-23807 and the per-pair systematics are shared.
9. **Registered expectations.** Report next to each measured Delta_anh(b) - Delta_anh(a): decision 17 1D values +1.85, +3.62, +0.84, -0.74, -0.32 and, for pair 2, decision 19's +3.51 to +3.81. Comparison only, never a rule input.
10. **Output.** `p12_scores.json`: inputs with paths and sha256, git hash, branch, rule texts, every per-structure and per-pair term above, categories, H1 to H4. JSON with `allow_nan=False`, full-precision floats. Stdout: a short markdown table (pair, P, ddF_harm, Delta b - a, ddF_corr, E_pair, category) and the H1 line. Windows paths.

## Known pitfalls
* A12 orientation is the most likely silent sign error: pair 1 is mp-23807 minus mp-625054, not the reverse.
* `delta_anh_meV_H` can be null while `delta_anh_unchecked_meV_H` is set. Never fall back to the unchecked value.
* sigma_d must come from independent seeds (`compare_runs` already refuses shared seeds; do not bypass it).
* d enters every structure's s_P; d_Fe only pair 2 and only at P32. Decision 18's "larger d of the two P32 checks" is superseded.
* The 0.19 meV/H line and `H1_above_0p19_meV_H` are informational, not gates. `bead_transfer_ok` is not a gate.
* The "harmonic sign" for pairs 4 and 5 is positive although the sign rule says negative; categories still use the harmonic sign, H3 and H4 are exploratory.
* Real JSONs today are partial. The scorer must run on the current tree and report pairs as not run, not crash.
