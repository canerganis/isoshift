# Spec: oh-scan-residual-p32 (extend src/isoshift_event/oh_scan_residual.py)

## Goal and why
Decision 19 (`docs/decisions/19-pimd-pair2-beads.md`, rule 3 and action 2; A15 in `docs/predictions/P12_pimd.md` section 2a) moves pair 2 (JVASP-54682, JVASP-92228) to P = 32, keeps P = 24 as its timing fallback, and redefines the A4b bound so it refers to the continuum target rather than to P = 128. Every s_P in the P12 scorer reads this bound: s_P,i = max(0.05, A_i(P), pilot terms). The extension must reproduce the chair's recompute and must not touch the committed P16 numbers that row 1 is already being judged against. No new MACE scans: the stored raw energies are the data, and the scans are frozen before any PIMD result exists.

Definitions (decision 19 rule 3, use as written, do not re-derive). For each scan q in {stretch, transfer} of a distinct H h, each mass model mu in {reduced, bare}, and each fit f in {degree 10, degree 8, not-a-knot spline}:
* r_f(P) = Delta_f(P) - Delta_f(128) for P in (16, 24, 32); t_f = Delta_f(128) - Delta_f(inf). Delta = Delta_anh in meV, same sign convention as the module.
* Per (q, mu) term: max_f |r_f(P)| + (max_f r_f(P) - min_f r_f(P)) + max_f |t_f|.
* A_i(P) = sum_h (m_h / N_H) * max over (q, mu) of that term. Directions and mass models are alternatives (maximised), never summed.
* Plateau sensitivity per (q, mu): b_poly(P) = |r_10(P)| + max(0.01, |r_11(P) - r_10(P)|, |r_12(P) - r_10(P)|), from polynomial degrees 10, 11 and 12. Aggregate per structure the same way as A_i. Sensitivity only: it never sets eligibility, never feeds `a4b_residual_meV_H` or `a4b_bound_meV_H`, and a failure in it must not invalidate the primary bound.

Owned files (the only files you may create or edit): `src/isoshift_event/oh_scan_residual.py`, `tests/test_oh_scan_residual.py`, `results/pimd/a4b_scan_residual.json`. Do not edit `isoshift/`, `docs/`, `pimd.py` or other modules. Do not commit; the conductor commits.

## Known pitfalls
* Joint grid convergence. `analyze_potential` converges all requested bead counts together, so adding 24 and 32 can change the converged grid and move P16 and P128 values in the last digits. The committed P16 values must still hold to 3 decimals; check it, do not assume it.
* Morse does not shrink as 1/P^2 between 16 and 32. With the committed numerics (grid converged, unchanged at half the grid step), the decision 17 Morse (omega_e 3600 cm^-1, D = 4.6 eV, reduced mass) gives r(16) = -0.053, r(24) = +0.014, r(32) = +0.020, t = +0.003 meV; bare mass -0.041, +0.017, +0.019, +0.0025. r crosses zero between P = 16 and 24 and only reaches the 1/P^2 regime above P = 32 (r(48) = 0.0122, r(64) = 0.0069, ratio close to (48/64)^2). A test asserting r(32) about r(16)/4 will fail for a correct code. Test the actual values within 0.003 meV, that |r(24)| and |r(32)| are below 0.4 |r(16)|, and the 1/P^2 ratio only where it holds.
* Higher-degree fits. Degrees 11 and 12 on 29 or so window points can be ill-conditioned or produce a spurious well or a non-confining extension. Report such a failure per scan and in the sensitivity field; it must not crash the run or alter the primary bound.
* The spline uses the degree-10 window bounds and extensions, and its own minimum and curvature for the harmonic reference, exactly as the committed `_spline_residuals`. A different choice changes the P = 24 and 32 numbers.
* Invalid or stale scans. A structure with any non-complete scan gets null bounds and a non-complete status, as `aggregate_sites` already does; the new fields follow the same rule.
* JSON stays small: no grids, no matrices, `allow_nan=False`. Windows paths. Floats written with full precision (3 decimals is the check, not the storage).
